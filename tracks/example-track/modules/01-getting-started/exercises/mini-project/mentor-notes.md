## Khi review bài này

- Chạy thử theo README của bài nộp. Không chạy được thì chưa đạt tiêu chí "Chạy được, đúng yêu cầu", dù code trông ổn.
- README cần nói: sản phẩm làm gì, cách chạy, ví dụ đầu vào và đầu ra.
- Chấm theo rubric trong `exercise.yaml`. Nhận xét nêu ít nhất một điểm làm tốt và một điểm cần sửa.

## Lỗi hay gặp

- Commit cả `node_modules/` hoặc file `.env`: nhắc thêm `.gitignore`, và đổi secret nếu đã lộ.
- Thiếu bước cài đặt trong README nên người khác không chạy được.

## Góp ý nên tránh

- Viết lại code giúp thành viên. Hãy gợi ý hướng sửa để họ tự làm.
